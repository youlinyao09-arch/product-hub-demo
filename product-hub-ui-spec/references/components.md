# 组件逐项规格

来源：`产品枢纽平台UIUE设计规范_2026.pdf` V1.0（2026-08-05 修订版）。色值总表见 [tokens.md](tokens.md)。

**输入类控件通用口径**（修订版全局统一）：内容色 `#3F4247`（输入文字）、占位符 `#B0B2BF`（初始文字）、边框 `#DCDDE5`、高 32px。下拉选项列表仍为 `#626469`。

## 操作反馈

### 操作二次提醒（弹窗）

- 字号：16/24（主字）、14/22（小字）
- 颜色：主字 `#2A2B33`、小字 `#3F4247`
- 图标：`#FFC53D`
- 结构：警示图标 + 标题 + 说明文字 + 右上关闭 + 底部「取消 | 确定」右对齐

用于有风险、不可逆的操作（删除、发布、激活），说明中必须写清后果。

### 操作成功 / 失败提醒（轻提示）

- 字号：14/22
- 颜色：失败 `#F3481C`、成功 `#16C566`、主字 `#2A2B33`
- 结构：状态图标 + 结果文字，页面顶部居中，自动消失，不阻断操作

结果通知一律用轻提示，**不要用弹窗告知成功**。

| 宽度 | 600px 默认；档位 400（小）/ 600（中）/ 800（大） |
| 高度 | 随内容自定义 |

| 圆角 | 8px（底部弹出模态面板 20px） |
| 文字颜色 | `#2A2B33`（标题 / 主要）、`#3F4247`（次要）、`#626469`（辅助） |

结构自上而下固定：**顶部标题 + 关闭按钮（左右布局）→ 中间内容区域 → 底部按钮区域（居右对齐）**。

## 卡片

| 项 | 值 |
|---|---|
| 字号 | 16/24（标题）；14/22（内容）；12/18（小字） |
| 颜色 | `#2A2B33`（标题 / 主要）、`#3F4247`（次要）、`#626469`（辅助） |
| 圆角 | 8px，纯白背景 |

- **布局**：头部含标题、状态标签、倒计时和进度条；中部是标准「标签 + 数值」列表；底部右对齐放置操作按钮。
- **视觉**：通过颜色区分语义（红 / 黄 / 绿底色代表状态等级，红色 / 灰色字体代表优先级），文字用深浅灰形成主次对比。
- **交互与自适应**：支持自适应拉伸，列表内容过长允许换行，进度条和状态标签随数据动态变化，整体是独立可复用的数据容器。

## 看板图表

配色见 [tokens.md](tokens.md)「图表专用」。通用容器规则：

- 每个图表放置于独立白色卡片中
- 头部：「图标 + 图表标题」左对齐，时间范围筛选器右对齐
- 图例居中置于绘图区上方
- 纵轴单位以小字标于左上角（如「单位（万）」）
- 轴线与网格线 `#EBEBF0`，轴标签 `#8C8F94`

### 各图表约束

- **柱状图**：单序列统一蓝；多序列优先「蓝 + 绿」，扩充依次追加紫、黄、粉
- **条形图**：与单柱图配色统一，仅布局方向区分
- **折线图**：配色逻辑与双列柱状图一致，线条粗细统一，可搭 10% 透明度同色区域填充
- **水波图**：单一目标完成率展示，仅用蓝色，不搭配多辅助色
- **饼图 / 环形图**：使用完全相同的色序，不随意调换色块顺序
- **雷达图**：多维度默认优先蓝、绿两套色系；新增维度依次紫、黄；线条透明度适度降低，避免色块重叠难以区分

## 布局

- 单屏设计基准：1440 × 900，12 栅格
- 区域构成：顶部标题区 + 主视觉区 + 图表区
- 三种范式：
  - 单屏布局一 `3x / 6x / 3x` —— 主视觉居中、两翼图表对称
  - 单屏布局二 `4x / 4x / 4x` —— 三等分平铺，无主次
  - 单屏布局三 `8x / 4x` —— 主视觉占左侧大区，右侧单列辅助

新页面应先套用其中一种，不自定义比例；顶部必须有标题区，其下分区在同一水平线对齐。
