## 一、色彩

### 品牌色

| 色值 | 用途 |
|---|---|
| `#2366FF` | 主要按钮、选中态、链接、重要引导图标、开关开启态 |

### 功能色

| 色值 | 语义 | 用途 |
|---|---|---|
| `#16C566` | 成功 | 成功、完成、开启状态 |
| `#F3481C` | 失败 / 告警 | 失败、错误、必填星号、告警标签 |
| `#FD921D` | 警告 / 注意 | 警告、不安全状态、注意类标签 |
| `#2366FF` | 链接 | 与品牌色同值，用于可点击文字 |

### 辅助色（图表点缀色）

| 序 | 色值 | 名称 |
|---|---|---|

| 3 | `#918DFC` | 浅紫 |
| 4 | `#FFD381` | 暖黄 |

### 中性色

| 色值 | 层级 | 用途 |
|---|---|---|
| `#2A2B33` | 强调文本 | 主标题、卡片标题、表格表头、菜单选中 |
| `#3F4247` | 次强调文本 | 正文内容、表单 Label、表格内容、**输入类控件内容** |
| `#626469` | 次要文本 | 提示文字、辅助信息、下拉选项列表 |

| `#F1F7FE` | 行 Hover | 表格行悬停背景 |
| `#F2F3F5` | 禁用填充 | 单选/复选禁用填充、滑动输入轨道、失效标签背景 |

## 二、字体

系统默认字体，不引入自定义字体（微软雅黑 / 思源黑体 / 苹方）。

### 标题 Medium (500)

| 层级 | 字号 | 行高 | 场景 |
|---|---|---|---|
| H1 | 36px | 48px | 一级大标题 |
| H2 | 18px | 26px | 二级标题、大分区标题 |
| H3 | 16px | 24px | 页面模块标题、弹窗标题 |

### 正文 Regular (400)

| 层级 | 字号 | 行高 | 场景 |
|---|---|---|---|
| 大号 | 16px | 24px | 正文大号文字、强调内容 |
| **中号（基准）** | **14px** | **22px** | 表格内容、表单输入、卡片正文 |
| 小号 | 13px | 20px | 次要信息、辅助说明、时间戳 |
| 最小 | 12px | 18px | 极小辅助文字、版权信息、提示小字 |

### 段落 Regular (400)

| 层级 | 字号 | 行高 | 场景 |
|---|---|---|---|
| 大号 | 16px | 32px | 详情页重点段落、长文正文 |
| 中号 | 14px | 28px | 长篇说明、产品介绍、富文本段落 |
| 最小 | 12px | 24px | 长篇次要注释、协议文本、细则说明 |

## 四、圆角与投影

| 容器 | 圆角 |
|---|---|

## 五、可复制片段

### CSS 变量

```css
:root{
  --brand:#2366FF;
  --success:#16C566;  --error:#F3481C;  --warning:#FD921D;
  --text-1:#2A2B33;   --text-2:#3F4247; --text-3:#626469; --text-4:#8C8F94;
  --disabled:#F2F3F5; --bg:#F5F7FA;     --white:#FFFFFF;
  --tag-invalid:#E3E6ED;   /* 标签「失效」态专用 */
  --border:#DCDDE5;   --split:#EBEBF0;  --head-bg:#F7F8FA;
  --row-hover:#F1F7FE;--fill-disabled:#F2F3F5;
  --input-border:#DCDDE5;  /* 输入框边框、描边 */
  --input-text:#3F4247;    /* 输入文字 */
  --placeholder:#B0B2BF;   /* 初始文字（占位符） */
  --chart-1:#6799FC;  --chart-2:#84EAB7;--chart-3:#918DFC;
  --chart-4:#FFD381;  --chart-5:#FF8EC3;
  --radius-card:8px;  --radius-sheet:20px;
  --shadow-card:0 4px 16px 0 rgba(72,90,129,.08);
}
```

| 失败色 | `#F3481C` | `@error-color` | `#f23030` | ❌ 不一致 |
| 警告色 | `#FD921D` | `@warning-color` | `#fa6432` | ❌ 不一致 |
| 强调文本 | `#2A2B33` | `@title-color` / `@blueBlack-9` | `#2A2B33` | ✅ 一致 |
| 次强调文本 | `#3F4247` | `@text-color` / `@blueBlack-8` | `#414352` | ⚠️ 接近但不同 |
| 次要文本 | `#626469` | `@blueBlack-7` | `#696b76` | ⚠️ 接近但不同 |

| 模块标题字号 | `16px` | `@font-size-md` | `16px` | ✅ 一致 |
| 控件高度 | `32px` | `@height-base` | `32px` | ✅ 一致 |
| 卡片圆角 | `8px` | `@border-radius-r4` | `8px` | ✅（注意 `@border-radius-base` 是 4px） |
| 底部弹出层圆角 | `20px` | `@border-radius-r7` | `20px` | ✅ 一致 |
| 卡片投影 | `0 4px 16px rgba(72,90,129,.08)` | `@card-shadow` | `0 1px 4px rgba(0,0,0,.04)` | ❌ 不一致 |

改主题变量会影响全部存量页面，属破坏性变更。新增页面遇到色值冲突时先确认口径，不要单方面全局替换。
