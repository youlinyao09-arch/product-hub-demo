# 产品枢纽平台 UIUE 设计规范（2026 V1.0，2026-08-05 修订版）

来源：`D:\03-工作\规范文件\产品枢纽平台UIUE设计规范_2026.pdf`（下划线版为最新；带连字符的 `-2026.pdf` 是首版，已废弃）。
可视化文档见 [docs/design-spec/index.html](../../../docs/design-spec/index.html)（浏览器打开，色值可点击复制）。

## 核心速查

写任何 UI 前先确认这几个硬性数值，它们覆盖了 80% 的走查问题：

| 项 | 值 |
|---|---|
| 品牌主色 | `#417FFB` |
| 正文字号 / 行高 | `14px / 22px`（界面基准） |
| 输入框、下拉、按钮高度 | `32px` |
| 表头 / 表格行高 | `48px` |
| **输入类控件内容色** | `#3F4247`（输入文字） |
| **输入类控件占位符** | `#B0B2BF`（初始文字）—— **不是** `#8C8F94` |
| 输入框边框 / 未选中描边 | `#DCDDE5` |
| 卡片、对话框圆角 | `8px`（底部弹出面板 `20px`） |
| 卡片投影 | `0 4px 16px 0 rgba(72,90,129,.08)` |
| 表格分割线 | `#EBEBF0` |
| 表格行 Hover | `#F1F7FE`；表头背景 `#F7F8FA` |
| 禁用填充 | `#F2F3F5` |

文字四层级不能串用。单序列图表一律蓝，双序列蓝+绿，扩展严格按上面顺序，**不调换色块顺序**。

## 字体

- 标题 **Medium (500)**：H1 36/48、H2 18/26、H3 16/24。不用 bold(700)。
- 正文 **Regular (400)**：16/24、**14/22（基准）**、13/20、12/18 —— 用于界面控件、表格、卡片。
- 段落 **Regular (400)**：16/32、14/28、12/24 —— 只用于详情正文、说明文档等连续阅读区。

同字号但行高不同，界面控件用正文行高，长文用段落行高，**不要混用**。

字体族一律跟随系统（苹方 / 微软雅黑 / 思源黑体），规范表格里的「苹方」是设计稿标注字体，**不是要求前端指定苹方**。

## 组件要点

- **输入类控件（全局统一）**：输入框、下拉、搜索多选、日期、富文本、描述说明、表单 Label、必填标识 —— 内容色 `#3F4247`、占位符 `#B0B2BF`、边框 `#DCDDE5`、高 32px。下拉选项列表仍是 `#626469`。
- **查询区**：控件全部 32px 高；底 `#F7F8FA`、圆角 8px、无描边；左筛选右按钮。按钮固定「查询（主要）+ 重置（次要）」，右对齐；导出等次按钮跟在重置后。字号统一 14/22。
- **表格**：表头 48px + `#F7F8FA` 背景 + `#2A2B33` 文字；行 48px + `#3F4247` 文字；操作列文字 `#417FFB`；空值以 `-` 占位。
- **列表页骨架**（对照「商业计划书任务发布」，后续列表必须套用，不要自创）：
  1. 白卡片 `.panel`（8px + `0 4px 16px rgba(72,90,129,.08)`）。
  2. **标题行** `.panel-hd`：左 `h1.page-title`（18/26、500、`#2A2B33`），右 `.btn.btn-primary`（高 32、`#417FFB`、圆角 4px）。若页上有 KPI 卡，标题+主按钮放在 KPI 上方 `.page-head`，列表卡内不再重复标题。
  3. **状态 Tab**（有则放在筛选区之上）：`.list-tabs` / `.bp-stabs` / `.req-tabs` / `.subtabs` / `.seg-tabs`。胶囊高 32、圆角 16。选中底 `#F0F7FF` + 字 `#417FFB` + 蓝圆数字徽标；未选底 `#F2F3F5` + 字 `#2A2B33` + 灰徽标。禁止下划线 Tab、文件夹式 Tab。
  4. **筛选区** `.filter-box`：搜索用 `.search-wrap`（放大镜在右侧），不要裸 `input.ctrl`。边框 `#DCDDE5`、内容 `#3F4247`、占位 `#B0B2BF`。
  5. **表格** `.table` + `.table-wrap`；**分页** `.pager` 右对齐。
  6. 标题不用 700；筛选区不用白底描边框。
- **表单**：模块标题 16/24；必填星号 `#F3481C` 在 Label 前；按钮组「否定在左（次要）/ 肯定在右（主要）」。
- **操作反馈**：不可逆操作（删除、发布、激活）走二次确认弹窗并说明后果；执行结果走轻提示，**不要用弹窗告知成功**。失败文字 `#F3481C`、成功 `#16C566`。
- **弹窗**：宽度取 400 / 600 / 800，默认 600；标题栏 48px；结构固定「标题+关闭 → 内容 → 底部按钮居右」。
- **卡片**：8px 圆角纯白；头部标题+状态标签+倒计时+进度条，中部「标签+数值」列表，底部操作右对齐。
- **标签**：状态点标签（圆点承担语义，文字统一 `#2A2B33`）用于表格列表；线性标签（底色+同色文字，高 24px）用于表单卡片。五态色值见 references/tokens.md。
- **导航**：步骤类三态 —— 已执行（勾选+实线）、执行中（实心序号+加重）、未执行（描边+灰字）；每步「主字 14px + 描述 12px」两行。
- **布局**：单屏基准 1440×900，12 栅格，三种范式 3/6/3、4/4/4、8/4，顶部必有标题区。新页面套用其一，不自定义比例。

## ⚠️ 与项目现有主题的差异

`product_pc/src/assets/theme/default/` 里的 antd Less 变量早于本规范，**主色不一致**：

| 规范 | 项目变量现值 |
|---|---|
| `#417FFB` 品牌色 | `@primary-color` = `#417FFB` |
| `#16C566` 成功 | `@success-color` = `#02b342` |
| `#F3481C` 失败 | `@error-color` = `#f23030` |
| `#FD921D` 警告 | `@warning-color` = `#fa6432` |
| `#3F4247` 正文 | `@text-color` = `#414352` |
| `0 4px 16px rgba(72,90,129,.08)` | `@card-shadow` = `0 1px 4px rgba(0,0,0,.04)` |

一致、可直接用变量的：`@blueBlack-9`(#2A2B33)、`@blueBlack-4`(#EBEBF0)、`@font-size-base`(14px)、`@font-size-md`(16px)、`@height-base`(32px)、`@border-radius-r4`(8px)、`@border-radius-r7`(20px)、`@padding-p2…p7`。

**处理原则**：涉及品牌色的新增视觉，先问用户是按规范写死 `#417FFB` 还是沿用 `@primary-color`——不要自行决定，也不要默认"规范优先"就全局改主题变量（会影响所有存量页面）。
注意 `@border-radius-base` 是 4px，卡片圆角要用 `@border-radius-r4`。

## 规范未覆盖

暗色主题、图标库规格、动效时长与缓动、1440 以外的响应式断点、无障碍对比度。这些场景**无标准可依，需与设计对齐后再落地，不要自行发挥**。

## 修订版仍存在的不一致

首版的 5 处矛盾已在 2026-08-05 修订版全部修正。当前仍需注意：

1. **查询区日期漏改**：查询区（P8）的「日期 / 日期区间」仍是 `#626469` / `#8C8F94`，而表单（P14）的同一控件已改为 `#3F4247` / `#B0B2BF`。**新代码统一按 `#3F4247` / `#B0B2BF` 写**，与其余输入类控件保持一致。
2. **色板描述过时**：色板 `#8C8F94` 仍写「用于输入框占位符」、`#626469` 仍写「用于输入框引导」，实际已被 `#B0B2BF` / `#3F4247` 取代。**输入类控件以组件页为准**。
3. **`#B0B2BF` 未列入色板**，但已是全平台占位符用色。
4. **`#E3E6ED` 已移出色板**，但标签规范（P21）的「失效」态仍在用它。标签失效态保留 `#E3E6ED`。

详见 references/tokens.md 末尾「修订记录与存疑点」。
